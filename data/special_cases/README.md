# 特殊判決書案例庫 (Special Cases)

本目錄存放用於測試、比對或特定業務情境的精選判決書案例。

專案目前從全量 **100,427 筆** 原始判決書中，依據「車禍特徵」篩選出共 **4,442 筆** 車禍案件，並依據「主要受傷部位」與「無受傷/財損」進行了詳細的分類與備份。

## 📁 分類結構說明

* 📁 **車禍 (Car Accidents)**
  * 📁 **手 (Hand)**：包含手骨折、斷指等傷害 (共 **818** 筆)
  * 📁 **腳 (Leg)**：包含腳骨折、膝蓋受傷等傷害 (共 **674** 筆)
  * 📁 **頭 (Head)**：包含腦震盪、頭骨折等傷害 (共 **547** 筆)
  * 📁 **胸軀 (Chest)**：包含肋骨、脊椎骨折等傷害 (共 **492** 筆)
  * 📁 **財損 (Property Damage)**：包含純車損、純酒駕及未提及上述主要傷勢之車禍案件 (共 **2,891** 筆)

## 📊 統計摘要
* 全量原始判決書：**100,427** 筆
* 篩選出車禍相關案件：**4,442** 筆
* 含有手、腳、頭、胸軀任一明確受傷特徵之案件 (去重後)：**1,551** 筆
* 其他類型車禍案件（如純酒駕、純車損及未列入主要傷勢的輕微挫傷案件）：**2,891** 筆

## 🗄️ Neo4j 資料庫匯入與寫入驗證 (Database Import Results)

本測試案例庫已於 **2026/7/3** 全量匯入至 Neo4j AuraDB 雲端圖資料庫，其寫入驗證結果如下：

* **成功匯入筆數**：**4,371** 筆 (成功率 **98.4%**)
* **略過／失敗筆數**：**71** 筆
* **失敗／略過原因說明**：
  * 這 71 筆檔案均隸屬於「懲戒法院」特別案件（例如父資料夾名稱為 `懲戒法院-懲戒法庭`）。
  * 由於系統的法院解析模組（`court_parser.ts`）目前僅設計支援一般的民刑事司法體系（地方法院、高等法院、最高法院），並不包含非一般法院的行政懲戒機構。
  * 腳本在解析法院名稱時回傳 `null`，為確保資料庫內 `Judgment` 節點法院欄位的真實性與結構乾淨，腳本主動對這些特別案件進行安全略過（Skip）不予寫入。
* **寫入防重複機制 (Idempotency)**：
  * 資料庫已建立 `CONSTRAINT FOR (j:Judgment) REQUIRE j.id IS UNIQUE` 唯一性約束。
  * 匯入腳本採用 Cypher 的 `MERGE` 與 `ON MATCH SET` 語法。多次或重複執行匯入時，只會對已存在的 `JID` 節點進行快速屬性 match，**100% 不會產生重複的垃圾資料或重複的圖譜關係**。
