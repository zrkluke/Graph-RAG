## 3. 連線設定與死結優化記錄

### 1. NEO4J_DATABASE 參數修正
在預設連線中，若直接傳入 `database="neo4j"` 會在 AuraDB Free 中觸發 `DatabaseNotFound` 錯誤。這是因為免費版會將實例的預設資料庫重命名為 Instance ID（例如 `6d4dc9d8`）。
- **解決方案**：在建立 `driver.session()` 時移除 `database` 參數，使 driver 自動利用其預設連線。這能確保程式無縫契合 `.env.local` 中配置的資料庫名稱。

### 2. 並行死結與重試機制
多執行緒並行寫入時，當多個 thread 同時嘗試對熱門實體（如 `Law: 中華民國刑法第185-3條`）進行 `MERGE`，會產生暫時性的死結競爭（Forseti Deadlock Wait Cycle）。
- **結果**：Neo4j Python Driver 內部自動重試機制成功在短暫延遲後重新提交並存檔，此現象未對匯入成功率造成影響，整體匯入順暢。
