## ADDED Requirements

### Requirement: 結合向量與篩選條件的 Cypher 檢索
系統必須提供檢索接口，將輸入的情境描述轉換為 1536 維向量後，在 Neo4j 的向量索引中找出最相似的 Section，並關聯回 Judgment。同時必須支援依據法院層級 (court_level) 與案件大類 (case_type) 進行屬性過濾，並回傳格式化後的列表。

#### Scenario: 成功進行情境檢索與過濾
- **WHEN** 輸入「被告酒後騎車撞傷行人並逃逸」情境，並設定過濾條件法院層級為「地方法院」
- **THEN** 系統回傳最相似的前 N 筆判決書列表，且列表中所有判決書的 `court_level` 均為「地方法院」，並按照相似度得分 (score) 由高到低排序

### Requirement: 圖譜擴展之關聯法條與關係人統計
系統在返回判決書列表時，必須在每一個判決書結果中，附帶其在圖譜中所關聯的關係人（法官、被告、原告）名單，以及引用的所有 `Law` 條文名單。

#### Scenario: 檢索結果中包含完整的圖譜關聯實體
- **WHEN** 混合檢索返回判決書
- **THEN** 回傳的每個判決書 JSON 字典內，皆包含去重後的 `judges`（法官列表）、`defendants`（被告列表）、`plaintiffs`（原告列表）以及 `cited_laws`（引用法條列表）
