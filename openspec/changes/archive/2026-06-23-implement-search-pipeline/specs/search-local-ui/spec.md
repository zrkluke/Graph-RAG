## ADDED Requirements

### Requirement: 建立本地 Gradio 檢索互動式 UI
系統必須提供一個基於 Gradio 的本地網頁 UI，提供輸入框供使用者輸入犯罪情境，並以按鈕觸發搜尋。

#### Scenario: 成功啟動與訪問 UI
- **WHEN** 於終端機執行啟動命令
- **THEN** 本地 UI 成功於預設埠（如 7860）啟動，且使用者可透過網頁瀏覽器進行訪問並進行資料查詢

### Requirement: 情境搜尋結果與篩選聯動展示
UI 介面必須提供「法院層級」與「案件種類」的下拉式選單篩選，並在結果展示區以表格或 HTML 卡片列表形式，呈現最相似判決書的法院名稱、主文、事實摘要、相似度分數、以及引用法規和相關人物。

#### Scenario: 情境檢索結果在網頁中完整渲染
- **WHEN** 於網頁輸入框中輸入情境並點擊「開始搜尋」
- **THEN** 結果區即時以結構化方式渲染出相似的判決字號、主文、引用法規、關係人列表與匹配的相似度得分
