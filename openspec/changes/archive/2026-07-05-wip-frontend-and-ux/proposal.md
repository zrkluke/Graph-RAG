# Proposal: 前端進階搜尋、視覺化與社群命名 UX 優化 (wip-frontend-and-ux)

## 1. 摘要 (Summary)
本提案旨在提升系統前端的檢索互動與視覺化性能。包含前端複合多條件篩選、法規共現高亮分析，實作圖譜節點的懶加載以應對大數據渲染卡頓，並實作動態社群語意命名，用易讀的法律概念（如：公共危險罪社群）取代無意義的社群整數標記。

## 2. 核心設計構想 (Design Concepts)
* **懶加載 (Lazy Loading)**：優化 vis-network 效能。預設僅渲染檢索出的一跳關係，當使用者雙擊或點擊節點時，非同步自後端加載該節點的二跳關係網。
* **動態社群語意命名**：由後端 API 統計該社群內出現次數最高且最具代表性的法規與罪名，動態生成社群標籤（如：「刑法第 185-3 條社群」），大幅增強圖譜的直觀易讀性。
