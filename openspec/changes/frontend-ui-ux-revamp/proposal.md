# Proposal: 前端 UI/UX 三階段深度優化重構 (frontend-ui-ux-revamp)

## 1. 摘要 (Summary)
本提案旨在解決「智慧型法律判決書 Graph RAG 搜尋系統」目前前端 UI 的三大痛點：
1. **全文閱讀受限**：原先的搜尋結果以三欄 Accordion 卡片呈現，強行在極窄（300px~400px）的欄位中展開主文與事實理由，閱讀極為吃力，且無法檢視完整判決書。
2. **版面配置單一**：系統目前被強迫綁定於「三欄演算法對比模式」，缺乏日常查閱法規與判決所需的經典雙欄/單欄閱讀模式。
3. **資訊雜亂無輔助**：判決書本文缺乏智慧化的實體高亮標記（被告、原告、法官、引用法條），且引用法規無法直接跳轉，增加了法律人員的檢索摩擦力。

為此，本提案將實作**右側滑出式詳情抽屜 (Drawer)**、**經典/比對雙佈局切換**、以及具備**實體高亮、法條超連結與段落導航**的智慧判決書閱讀器。

---

## 2. 動機與背景 (Motivation & Background)
* **閱讀痛點**：法律判決書動輒數千字，排版在一長條的狹窄欄位中會極大損害閱讀體驗。
* **使用場景分歧**：在展示/測試搜尋演算法時，我們需要「三欄比對」；但在實際使用系統尋找案例時，我們需要「經典雙欄（左清單、右全文）」以利流暢瀏覽。
* **檢索效率**：法律判決書中提及的法規常需二次查詢，若系統能將法規自動化為連結，並高亮關係人，能大幅提高律師或法官的辦案效率。

---

## 3. 解決方案 (Proposed Solution)

本變更將分為三個互相並存的階段實作：

### 階段一：滑出式詳情抽屜 (Slide-over Drawer)
* 在頁面中導入 `selectedItem` 狀態。
* 使用 `fixed inset-y-0 right-0 z-50 w-full md:w-3/5` 實作一個覆蓋在上層的側邊欄抽屜，以最寬敞、最易讀的排版渲染該判決書的全部內容。

### 階段二：經典/比對佈局切換 (Layout Mode Switching)
* 引入 `layoutMode` 狀態（`classic` 與 `compare`）。
* **對比模式 (`compare`)**：維持現有的三欄演算法比對。卡片中新增「📖 閱讀全文」按鈕以點開滑出式抽屜。
* **經典模式 (`classic`)**：呈現雙欄排列：
  * **左側 (35% 寬度)**：渲染簡潔的 RRF 混合檢索結果清單，移除非必要的 Accordion 展開元素。
  * **右側 (65% 寬度)**：常駐型全文閱讀器，點擊左側項目即可平滑載入，提供流暢的閱讀動線。

### 階段三：智慧閱讀器 (Smart Verdict Reader)
* **實體高亮 (Entity Highlighting)**：以色彩標籤區分「被告」、「原告」、「法官」與「引用法條」。
* **法條超連結**：點選法規後自動跳轉至中華民國全國法規資料庫的對應法規搜尋頁。
* **段落導航 (Table of Contents)**：於閱讀器旁建立「主文」與「事實與理由」的跳轉錨點，點擊平滑滾動。
* **微互動與 Skeleton**：使用 Tailwind 實作卡片 Hover 浮動效果與骨架屏（Skeleton Screen）載入動畫。

---

## 4. 影響評估 (Impact)
* **優點**：
  * 大幅提升使用者的閱讀效率與系統的視覺品質。
  * 完美相容演算法評估（比對模式）與實際搜尋查閱（經典模式）。
  * 0 外部重量級套件依賴，純以 Next.js + Tailwind CSS 實作，保持輕量高效。
* **缺點**：
  * `page.tsx` 的程式碼結構會變得稍微複雜，需進行適當的組件拆分或結構化管理。
