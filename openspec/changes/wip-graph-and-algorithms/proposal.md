# Proposal: 知識圖譜 Schema 擴充與向量檢索圖演算法優化 (wip-graph-and-algorithms)

## 1. 摘要 (Summary)
本提案旨在優化本專案的圖資料模型與檢索演算法。包含進行圖譜 Schema 的擴充（如罪名、關鍵事證、多重標籤），設計長遠的圖譜推理能力與圖文分離架構，並建立量化的檢索品質評估與分數正規化機制，以發揮 Graph RAG 的真實價值。

## 2. 核心設計構想 (Design Concepts)
* **Schema 擴充**：引入 `:Crime`（罪名）與 `:Item`（關鍵事證）節點，深化實體鏈結關係。
* **強約束過濾與多跳推理**：利用圖譜關係對向量檢索回傳的候選判決進行交集過濾（例如：向量搜尋相似案情 + 圖譜篩選「無罪」且「特定法條」），並支援順著圖關係推薦二跳關係。
* **評估與正規化**：建立 20-30 個標準查詢的 Gold Standard 測試集；實施 Cosine 相似度與 Lucene 全文檢索分數的正規化，以便進行精確的混合排序調優。
