## ADDED Requirements

### Requirement: 支援多個項目同時展開的折疊面板 UI
前端搜尋結果列表的 Accordion 折疊面板必須允許使用者同時展開多個項目，方便進行判決內容的跨案比對，而不是傳統「點開 A 就自動關閉 B」的互斥展開。

#### Scenario: 同時點開並展開多個判決書詳情
- **WHEN** 使用者在搜尋結果列表中點開第一個判決書，接著在不關閉它的情況下點開第二個判決書
- **THEN** 畫面中兩個判決書的詳情內容面板皆應處於展開狀態，且 Accordion 面板的標題僅顯示該判決書的名稱（例如：`臺灣臺北地方法院 112 年度交簡字第 123 號刑事判決`）。
